 Technical Analysis Using R – Visualization Phase

Student:Hanan Al Saka

This project is an interactive stock analysis dashboard developed using R Shiny.

The dashboard retrieves historical Apple (AAPL) stock data from Yahoo Finance and provides:

- Daily, weekly, and monthly candlestick charts
- Moving Averages, RSI, and MACD indicators
- Interactive date-range selection
- Buy, Sell, and Hold signals based on RSI
